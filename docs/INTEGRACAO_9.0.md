# Integração EvoluFisico 9.0-beta

Fonte recebida: `Evolufisico2-main.zip` do repositório `dutrafg/Evolufisico2`.

A distribuição desktop deve incluir `index.html`, `assets/`, ícones, manifest e demais recursos estáticos em `src/EvoluFisico.Desktop/wwwroot/`.

O armazenamento atual utiliza APIs de navegador (incluindo IndexedDB), portanto a migração para SQLite exige uma etapa própria com exportação/importação e testes de integridade. Não substitua dados reais antes de validar backups.

O frontend completo ainda não foi enviado a este repositório. Não considerar a versão compilável até a inclusão desses recursos, validação da compilação e QA em Windows.
